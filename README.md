# Col Tur

Antalya şehir turları, tekne gezileri ve kültür rotaları için hazırlanmış modern, mobil uyumlu tur sitesi.

## Özellikler

- Tur arama ve kategori filtreleri
- Ayrıntılı tur kartları ve fiyat gösterimi
- Rezervasyon talep arayüzü
- Mobil menü ve sabit mobil rezervasyon çubuğu
- GitHub Pages için otomatik yayın akışı

## Yerel geliştirme

```bash
npm ci
npm run dev
```

Üretim çıktısı için:

```bash
npm run build
```
